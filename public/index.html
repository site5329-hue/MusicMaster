ABOUT

درباره نسخه 1.4

Music Master 1.4 یک بازطراحی گسترده برای رسیدن به ظاهر یکپارچه‌تر در موبایل و کامپیوتر است. رنگ اصلی رابط به آبی عمیق و آبی روشن منتقل شده و کارت‌ها با شفافیت و blur کنترل‌شده ساخته شده‌اند.

در این نسخه Hyper و بهینه‌ساز حذف شده‌اند تا معماری رابط ساده‌تر و قابل کنترل‌تر باشد. تمرکز روی کیفیت پایه سایت، انیمیشن‌های نرم، آیکون‌های گرد و نورانی، ناوبری جدید و ابزارهای مدیریتی قرار گرفته است.

بخش رفع باگ یک روند 20 ثانیه‌ای دارد. چهار مرحله هر کدام پنج ثانیه طول می‌کشند تا کاربر بتواند روند بررسی را واضح ببیند.

بخش Server Cloud در این نسخه داده‌های فعالیت را در فضای ذخیره‌سازی مرورگر نگه می‌دارد. این کار برای بکاپ واقعی ابری کافی نیست، اما پایه‌ای مناسب برای اتصال بعدی به API و دیتابیس است.

برای امنیت، این نسخه ادعای بررسی امنیت سرور نمی‌کند. جاوااسکریپت داخل مرورگر نمی‌تواند به شکل قابل اعتماد امنیت یک سرور را تأیید کند؛ بنابراین مرکز رفع باگ فقط بررسی‌های محلی و قابل انجام در فرانت‌اند را انجام می‌دهد.
